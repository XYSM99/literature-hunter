# 筛选、版本识别与去重

## 一、可信度分级（高 → 低）

| 级别 | 来源 | 处理原则 |
|---|---|---|
| A | 发布机构官网（一手发布） | 首选，作为权威依据 |
| B | 机构官方知识库 / 编号永久存档 | 等同官网，尤其用于历史版本 |
| C | 合作机构、兄弟机构的授权转载 | 可用，注明来源；与 A/B 存在差异时以原始发布机构版本为准 |
| D | 第三方资料站、文库、个人博客 | 仅在 A–C 均不可得时使用，必须标注「二手来源、未经校验」 |
| E | 二手转述、机器翻译摘录、未标注出处的摘要 | 不采用为原文依据，仅可作线索 |

**规则**：同一文档有多个来源时，优先取 A/B；确需采用 C/D 时，交付物中必须写明实际来源与差异（例如篇幅、版本、是否为节选）。

## 二、版本识别

### 找版本三要素

1. **封面/首页标记**：很多手册首页直接印 `January 2026`、`Version X`
2. **文件名与目录**：`_2024`、`_20250801`、`v2.1`
3. **站点元信息**：机构知识库记录页通常有 `Published Date`、`Pages in Document`、`File Type`

### 元信息缺失时的处理

- 页数：不要照抄站点标称，**下载后自行解析**为准（站点常缺项或过期）
- 生效日期：从文件内的「Revises effective January 1, xxxx」类表述提取
- 若两处冲突：以文件内自述为准，交付表中标注差异

### 「版本」还是「修订」

- **年度版**（如手册每年 1 月 1 日生效）→ 算独立版本
- **同版内的补篇/修订说明**（Summary of Updates / Errata）→ 不算新版本，但应作为附件记录

## 三、去重规则

同一内容可能同时存在于：官网 current 链接、年份链接、知识库编号记录、镜像站。**去重依据**：

1. 优先比对 **`Pages in Document` + 文件大小**：页数与大小同时吻合 → 判为同一文件
2. 首页前 200 字符文本一致 → 判为相同版本
3. 页数不同但年份相同 → 可能是「修订增补版」，保留两者并标注差异

## 四、时效判断

- 技术手册、临床指南：**优先现行版**，历史版本仅在需要版本沿革对比时保留
- 统计报告：核对统计周期（报告年份 vs 数据年份），两者常差一年
- 已被新版文件取代的内容（带 Replaces / Superseded by 标记）：保留但注明「已由 xx 版取代」

## 五、完整性清单（交付前逐项确认）

- [ ] 来源是否为 A/B 级
- [ ] 版本年份是否确认无误（至少两处证据互相印证）
- [ ] 页数/大小为实际解析值，非照抄标称
- [ ] PDF 是否完整（含 `%%EOF`）
- [ ] 是否与其他候选文件重复
- [ ] 是否已剔除二手来源，或已标注
- [ ] 交付内容中无账号、密钥、本地绝对路径
